Booking functionality for WordPress.

== Description ==

Booking Plugin adds booking/reservation functionality to WordPress.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/booking-plugin` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
